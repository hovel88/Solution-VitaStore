## Базовые предположения

* Количество магазинов = 100
* Горизонт расчёта = 3 года
* Инфляция = 7%
* Цены взяты при курсе USD на момент расчета = 87 руб

Детали расчета вынесены в [Excel-таблицу](./TCO-and-ROI-analysis.xlsx)

## Ключевые результаты

| Показатель | Значение |
| -- | -- |
| **TCO AS-IS (всего за 3 года)** | 366 175 390 руб |
| **TCO TO-BE (всего за 3 года)** | 246 813 718 руб |
| **Экономия** | 119 361 672 руб (32.6%) |
| **Инвестиции в миграцию** | 13 000 000 руб |
| **Срок окупаемости** | 4 месяца |
| **ROI за 3 года** | 818% |

### Основные факторы экономии

1. **ИТ-поддержка:** -75% (выезды инженеров практически исключены)
2. **Оборудование:** -66% (серверы в подсобках заменены на Raspberry Pi или Intel NUC)
3. **Лицензии:** -16.4% (отказ от Windows Server + SQL Server, используем облачные решения)
4. **Инфраструктура:** -88.8% (меньше расходов на электроэнергию, и интернет)

## Итог

Проект перехода VitaStore на облачную архитектуру оказывается экономически оправданным.

Расчет производился для 100 магазинов, при масштабировании на все 500 магазинов теоретически экономия составит более 595 млн за 3 года.

Срок реализации инвестиций в модернизацию — 1 год, срок окупаемости инвестиций — 4 месяца. Учитывая, что внедрять модернизации можно начинать поэтапно, начиная через первые 3-4 месяца, — это означает, что уже к концу первого года после начала миграции проект начнет выходить в чистую прибыль.
